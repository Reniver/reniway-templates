# FANUC — Power Motion i

CNC control family by FANUC (control manufacturer).

**Ethernet integration:** FOCAS2 Ethernet

_No templates yet._ To add one, follow the `create-edge-template` skill
(`.claude/skills/create-edge-template/SKILL.md`) and use an existing template
(e.g. `HEIDENHAIN/TNC640`, `FANUC/Series30i-31i-32i`) as a reference.

> Protocol/option availability varies by control software version and purchased
> options — verify against the specific machine before building a template.
